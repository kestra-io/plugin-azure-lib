# AGENTS.md

## Why
- This plugin integrates Kestra with azure lib.
- It groups workflow components for packages such as `batch`, `storage`.

## What
- Provides plugin components under `io.kestra.plugin.azure.shared`.
- Includes classes such as `BatchService`, `DefaultJobResumeStrategy`, `JobResumeStrategy`, `BlobOutput`.
- Organizes features across packages such as `batch`, `storage`.
